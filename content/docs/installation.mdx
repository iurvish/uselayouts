---
title: Installation
description: How to get started with uselayouts in your project.
---

uselayouts is a [shadcn](https://ui.shadcn.com/docs/cli) registry. Add the namespace once, then install any component with `@uselayouts/{name}`.

## 1. Add the registry

In your project's `components.json`:

```json
{
  "registries": {
    "@uselayouts": "https://uselayouts.com/r/{name}.json"
  }
}
```

## 2. Add a component

```bash
npx shadcn@latest add @uselayouts/discrete-tabs
```

pnpm, yarn, and bun work the same way:

```bash
pnpm dlx shadcn@latest add @uselayouts/discrete-tabs
yarn dlx shadcn@latest add @uselayouts/discrete-tabs
bunx --bun shadcn@latest add @uselayouts/discrete-tabs
```

You can add several at once:

```bash
npx shadcn@latest add @uselayouts/delete-button @uselayouts/status-button
```

## 3. Prerequisites

Components expect:

- **React**
- **Tailwind CSS**
- **Motion** (and other deps the CLI installs for you)

Browse the [components](/docs/components/pricing-card) gallery, copy the command, and run it in your app.
