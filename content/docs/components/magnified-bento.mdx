---

## Features

- **Marquee rows**: Three lines of chips drift in opposite directions — Discovery, Launch, Security, and the rest.
- **Draggable lens**: A circular glass follows the pointer and magnifies the chips underneath.
- **Dual layer**: The magnified copy stays locked to the same chips, so it never drifts out of register.
- **Card chrome**: Title and a short line sit under the window — “Intelligent Workflows.”
- **Lens shine**: Highlights on the glass so it reads as a real loupe.

## Usage

This is a feature illustration, not a search UI. Edit `TAG_ROWS` and the title/description in `CONFIG`. Needs pointer drag (or hover) and a card-sized well. Don’t cover it with other interactive layers.

```tsx
import MagnifiedBento from "@/components/magnified-bento";

export default function Page() {
  return (
    <div className="h-screen flex items-center justify-center">
      <MagnifiedBento />
    </div>
  );
}
```

## Where to use

- Agency or studio capability tiles
- SaaS “workflow” bento grids
- Skills or services marketing
- Product pages about search or tagging
- Landing feature rows
