## Features

- **Falling chips**: Each card drops into the bucket, then the next one follows on a loop.
- **Layered SVG bowl**: The hopper is a real shape with blur and depth — not a rounded rectangle.
- **Icon + claim**: Production Ready, Fluid Motion, Accessible, Modern Design — short and readable in the chip.
- **Continuous cycle**: Every two seconds the front chip rotates out so the bucket never sits still.
- **No 3D engine**: Motion and SVG give you the toss without WebGL.

## Usage

Use it as a feature explainer, not a form. Swap `INITIAL_CHIPS` for your own titles, lines, and icons. Give it a wide, short stage (it wants landscape). Autoplay is the point — don’t put it next to something that also loops.

```tsx
import Bucket from "@/components/bucket";

export default function Page() {
  return (
    <div className="h-screen flex items-center justify-center">
      <Bucket />
    </div>
  );
}
```

## Where to use
