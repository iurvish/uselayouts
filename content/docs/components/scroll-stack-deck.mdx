title: Scroll Stack Deck
description: Scroll-linked project cards that pin in the viewport and stack, scale, and settle as you move down the page.
---

## Features

- **Sticky viewport**: A `5 × 110vh` track pins a full-screen stage so the stack stays in view while you scroll.
- **Scroll is the scrubber**: Motion `useScroll` maps progress to each card’s `y` and `scale` — later work slides up, earlier work recedes.
- **Spring-smoothed progress**: A light spring on `scrollYProgress` keeps the stack from stuttering on wheel ticks.
- **Tabbed folder cards**: Numbered tabs (01 · Loom, 02 · Meridian) sit on colored folder bodies with copy + still.
- **Lenis on the window**: Optional smooth wheel for a real landing page. Pass `container` and `enableLenis={false}` inside nested overflow (this docs preview).
- **Landing-page defaults**: Title, subtitle, scroll cue, and footer — hide them with empty strings / `showFooter={false}`.

## Usage

This needs a long page. Don’t drop it in a short section — there’s nothing to scroll. Swap `DEFAULT_PROJECTS` for your work (title, description, still, tint). Images should be wide. Pair it with a case-study or studio homepage, not a dashboard.

```tsx
import ScrollStackDeck from "@/components/scroll-stack-deck";

export default function Example() {
  return <ScrollStackDeck />;
}
```

## Where to use

- Studio or agency homepages
- Case-study index pages
- Product “selected work” stories
- Architecture project sites
- Annual recap or lookbook pages
