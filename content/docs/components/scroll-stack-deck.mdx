---
title: Scroll Stack Deck
description: A scroll-driven project showcase where cards stack, scale, and settle as you move through the page.
---

## Usage

```tsx
import ScrollStackDeck from "@/components/scroll-stack-deck";

export default function Example() {
  return <ScrollStackDeck />;
}
```

## Features

- Scroll-linked card stacking with spring-smoothed progress
- Optional Lenis smooth scrolling
- Customizable projects, titles, and footer
