## Features

- **Scattered stack**: Three photos sit rotated and overlapping, like prints on a desk.
- **Explore to grid**: Click through and the pile lays out into a full gallery.
- **Shared layout**: Images keep their identity as they travel from stack to cell.
- **Hover lift**: Individual prints respond before you commit to the grid.
- **Outside click**: Click away and it can fold back to the pile.

## Usage

Swap the `PHOTOS` array — you want at least a handful of stills. Needs a click and a reasonably wide stage. Collapsed, it’s a teaser; expanded, it’s the gallery. Don’t nest it in a tiny card.

```tsx
import ExpandableGallery from "@/components/expandable-gallery";

export default function Page() {
  return <ExpandableGallery />;
}
```
