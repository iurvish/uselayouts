---
title: Infinite Canvas
description: A free-panning product canvas that tiles forever — drag, scroll, and skim an endless grid of images and captions.
---

## Usage

```tsx
import InfiniteGrid from "@/components/infinite-grid";

export default function Example() {
  return <InfiniteGrid />;
}
```

## Features

- **Endless tiled canvas**: A 3×3 block wrap so the grid never runs out of space.
- **Drag to pan**: Pointer drag with inertia and momentum coasting.
- **Wheel & trackpad**: Two-axis scrolling with the same soft follow.
- **Velocity skew**: Subtle skew tied to pan speed for physical feel.
- **Image + caption cells**: Product shots with title and price — no card chrome.
- **Ambient blobs**: Optional soft background motion behind the grid.
