---

## Features

- **Thumb cut**: A hole on the right edge of the sleeve so the letter always shows through.
- **Peeked sheet**: The cream page sits a little outside the folder at rest, so you can tell something is inside.
- **Extract and flip**: Click the folder — the letter slides out, turns over, and settles in front.
- **Orbit cover**: Ellipses on charcoal, with a short title and one-line description.
- **Typed memo**: The tucked face is a brief; the back is the closed-session note.

## Usage

One folder, one letter. Swap title, subtitle, badge, message, and punchline. Needs a dark ground and a click — not a swipe, not a stack. Use it as a reveal, not navigation.

```tsx
import ConfidentialFolder from "@/components/confidential-folder";

export default function Example() {
  return <ConfidentialFolder />;
}
```

## Where to use

- Agency “peek inside” heroes
- Launch teaser pages
- Recruiting or culture pages
- Case-study covers that want a reveal
- Event or invite microsites
