---

## Features

- **Sleeve to card**: Click the folder and a sheet extracts, unflips, and settles in the foreground.
- **DO NOT OPEN tab**: A red vertical stamp on the edge sells the “confidential” gag.
- **Phased motion**: Tucked → extracting → landing → revealed, then the reverse on close.
- **Badge and punchline**: File number, “Internal use only,” and a short line once the card is out.
- **Sticker beat**: A small looping sticker on the revealed card so it feels like a real file.

## Usage

This is a one-shot interaction — one folder, one secret. Swap title, badge, message, and sticker. Needs a tall preview and a click; there’s no swipe. Use it as a playful Easter egg, not a navigation pattern.

```tsx
import ConfidentialFolder from "@/components/confidential-folder";

export default function Example() {
  return <ConfidentialFolder />;
}
```

## Where to use

- Agency “peek inside” heroes
- Launch teaser pages
- Recruiting or culture pages
- Case-study covers that want a reveal
- Event or invite microsites
