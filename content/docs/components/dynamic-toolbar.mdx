---
title: Dynamic Toolbar
description: An icon strip that resizes as you page between primary tools and a second set.
---

## Features

- **Two trays**: Inbox, Messages, Paint, Tags on the first page; Image, Archive, Reload, Delete on the second.
- **Width follows content**: Measured bounds so the pill grows and shrinks instead of leaving empty space.
- **Blur on the seam**: Edge icons soften during the swap so the cut doesn’t feel harsh.
- **Pager arrows**: Left/right move between the two tool sets.
- **Danger sits last**: Delete is red and lives on the overflow page, not in the first glance.

## Usage

Treat it like a floating editor bar. Swap the `primaryTools` / `secondaryTools` arrays. Needs a short, wide stage and enough height so the arrows don’t collide. Wire each icon to an action — the demo is visual only.

```tsx
import ExpandedToolbar from "@/components/dynamic-toolbar";

export default function Page() {
  return (
    <div className="flex items-center justify-center h-[200px] w-full">
      <ExpandedToolbar />
    </div>
  );
}
```

## Where to use

- Canvas or design-tool chrome
- Email or notes editors
- Image annotation bars
- Admin “quick actions” strips
- Prototype app shells
