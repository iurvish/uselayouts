## Features

- **Twin circles**: A filter glyph beside the selected type (tasks, events, reminders…).
- **Morphing panel**: The filter button becomes a list via a shared `layoutId`.
- **Staggered rows**: Options slide in one after another, not all at once.
- **Check on the pick**: The active row gets a filled tick.
- **Icon as summary**: When the list closes, the right circle still shows what you chose.

## Usage

Use it as a compact filter, not a full faceted search. Edit `filterKeys` for names and icons. Needs a click and a little space for the 72px panel. Pair it with a list that actually filters — this is the control.

```tsx
import FilterInteraction from "@/components/filter-interaction";

export default function Page() {
  return (
    <div className="flex items-center justify-center h-[400px] w-full">
      <FilterInteraction />
    </div>
  );
}
```

## Where to use

- Calendar or planner toolbars
- Task apps (tasks, meetings, celebrations)
- Mobile filter sheets
- Dashboard widget headers
- Notification type pickers
