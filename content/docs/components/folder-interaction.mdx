## Usage

```tsx
import FolderInteraction from "@/components/folder-interaction";

export default function Example() {
  return <FolderInteraction />;
}
```

## Features

- Click to open: One tap flips the folder flap on the X axis.
- Document fan: Three pages spring to the left, center, and right with a little stagger.
- Inset lighting: The pocket has an inner shadow so it reads as a real sleeve.
- Frosted front: The flap uses blur and a custom SVG silhouette.
- Click again to close: Papers tuck back in; the flap drops.
