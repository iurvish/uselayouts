## Features

- **Click to open**: One tap flips the folder flap on the X axis.
- **Document fan**: Three pages spring to the left, center, and right with a little stagger.
- **Inset lighting**: The pocket has an inner shadow so it reads as a real sleeve.
- **Frosted front**: The flap uses blur and a custom SVG silhouette.
- **Click again to close**: Papers tuck back in; the flap drops.

## Usage

A single object, not a file manager. Drop it as a visual for docs, decks, or “what’s in the brief.” Needs a click and a medium square of space. Swap the inner page content if you want real titles on the sheets.

```tsx
import FolderInteraction from "@/components/folder-interaction";

export default function Page() {
  return (
    <div className="flex items-center justify-center min-h-[400px] w-full">
      <FolderInteraction />
    </div>
  );
}
```

## Where to use

- Docs or resource hubs
- Agency “the brief” moments

- Onboarding that introduces a packet of assets
