## Features

- **Collapsed dock**: Five icons sit in a pill until you pick one.
- **Expanding trays**: Home, search, alerts, profile, and theme each open their own little menu.
- **Measured height**: The tray grows with `useMeasure` so it doesn’t jump when content changes.
- **Theme switcher**: Light, dark, and system live in the last slot.
- **Click outside to close**: The dock tucks back down when you tap away.

## Usage

Park it at the bottom of a phone-width layout or a floating demo. You’ll edit the `HOME_ITEMS` / nav arrays for labels and icons. Needs a bit of vertical room for the expanded tray. Not a full app shell — think composer, not navigation bar.

```tsx
import BottomMenu from "@/components/bottom-menu";

export default function Page() {
  return <BottomMenu />;
}
```

## Where to use

- Mobile app marketing pages
- Note, voice, or capture composers
- Prototype shells for a consumer app
- Settings previews (theme, profile)
- Floating action menus on a landing demo
