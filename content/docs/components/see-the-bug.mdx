## Features

- **Folder tiles**: Numbered cards sit like files, not generic rectangles.
- **Hover lift**: The folder comes forward; a sparkle, gem, or rocket floats above.
- **Photo peek**: A still shows through the folder body so each card has a scene.
- **High-contrast paper**: Dark and light folders on a near-black stage.
- **Optional links**: Each card can be an `<a>` if you pass `href`.

## Usage

Three cards in a row is the layout. Swap titles, folder colors, stills, and the object image. Needs hover (or a tap) and a dark-ish stage. Don’t add a fourth unless you wrap the row.

```tsx
import SeeTheBug from "@/components/see-the-bug";

export default function Example() {
  return <SeeTheBug />;
}
```

## Where to use

- Product pillar cards (intel, UI, speed)
- Studio offering grids
- Launch pages with three promises
- Case-study indexes
- Dark-theme marketing sections
