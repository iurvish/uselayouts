---
title: Overlapping Slider
description: A fanned card stack you drag sideways — each card tucks under the next and tilts as it leaves.
---

## Features

- **Overlap**: Cards sit at a negative margin so each one covers most of the last. Tune `overlapFactor` (0.1–0.85).
- **Drag then snap**: Pointer drag with a flick threshold — a fast swipe jumps a card, a slow one settles on the nearest.
- **Tilt as they leave**: Off-center cards rotate from the bottom-left, shrink a little, and drop.
- **Dots and arrows**: Jump, or step one at a time. Hide either with `showDots` / `showArrows`.
- **Any card**: Pass `children`, or `items` plus `renderItem`. The demo uses portrait cards; swap in products, quotes, anything.

## Usage

Needs a wide stage so the fan can breathe (the demo cards are 260×360). Drop in your own slides, or keep the built-in profiles.

```tsx
import OverlappingSlider from "@/components/overlapping-slider";

export default function Page() {
  return <OverlappingSlider />;
}
```

To drive it from data:

```tsx
import { OverlappingSlider, ProfileCard } from "@/components/overlapping-slider";

<OverlappingSlider
  items={profiles}
  renderItem={(card) => <ProfileCard card={card} />}
  cardWidth={260}
  cardHeight={360}
  overlapFactor={0.5}
/>
```

## Where to use

- Team or speaker lineups
- Profile or dating browse
- Lookbooks
- Testimonial portraits
- Product pickers that should feel like a stack, not a strip
