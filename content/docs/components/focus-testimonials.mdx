## Features

- **Focus by hover**: Dim the others, bring one voice to the front.
- **Author tooltip**: Name, role, and company float near the pointer.
- **Expand for more**: A control reveals additional quotes beyond the first row.
- **Quote stays readable**: The line of copy is the hero; avatars are the index.
- **Click isn’t required**: Desktop hover does the work; expansion covers extra names.

## Usage

You need a set of quotes with avatars, names, and companies. Hover is the main interaction, so it’s happiest on desktop marketing pages. Swap `INITIAL_TESTIMONIALS` / extra lists. Don’t put it in a tiny column — the row of faces needs to breathe.

```tsx
import FocusTestimonials from "@/components/focus-testimonials";

export default function Example() {
  return <FocusTestimonials />;
}
```

## Where to use

- Homepage social proof
- Pricing pages under the plans
- Case-study outros
- Agency client walls
- Launch pages with a few strong quotes
