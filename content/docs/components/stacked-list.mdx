---

## Features

- **Stacked preview**: A few avatars and names sit as the collapsed widget.
- **Morph to directory**: Expand and the rest of the team slides out of the same card.
- **Search in both states**: Filter without leaving the widget.
- **Role badges**: PM, designer, data, creator — color-coded.
- **Online ticks**: Presence on the preview so it feels like a live team.

## Usage

Point `ALL_MEMBERS` at your people (name, role, avatar, status). The collapsed view shows actives; expand for everyone. Needs a medium card width. Wire search and add to your data — the demo is local. Happy in a sidebar or a project header.

```tsx
import StackedList from "@/components/stacked-list";

export default function Page() {
  return <StackedList />;
}
```

## Where to use

- Project or workspace sidebars
- Team widgets on a dashboard
- Invite / members settings
- Community directories
- “Who’s on this file” panels
