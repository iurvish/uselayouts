## Usage

```tsx
import PaperShredButton from "@/components/paper-shred-button";

export default function Example() {
  return <PaperShredButton />;
}
```

## Features

- Preview on hover or focus: The button lifts, the trash icon tilts, and a white page appears above it.
- Shred on click: The page clips away from the bottom. SVG strips draw in underneath.
- Disabled while shredding: The button stays off through `shredding` and `shredded`.
- Auto-reset: After the strips settle, it returns to idle so you can run it again.
- Reduced motion: Near-instant transitions, no long path drawing, a short shred delay.
- Needs `motion`. This is a visual demo, not a real delete.
