## Features

- **Stacked widths**: Cards behind get narrower and offset so the pile feels like a deck, not a carousel.
- **Swipe the top**: Drag the front card sideways to go next or previous.
- **Desktop / mobile toggle**: A pill switches the stage so you can preview both layouts.
- **Autoplay with pause**: It can advance on a timer and rest while you hover.
- **Caption, title, still**: Each card is a small case study, not a nameless image.

## Usage

Pass a few case studies with image, title, and a line of copy. Needs a tall stage (~545px). Swipe on the top card; click the ones behind to jump. Keyboard and pagination exist if you leave them on. This is a showcase, not a blog index.

```tsx
import Rollingcardstack from "@/components/rollingcardstack";

export default function Example() {
  return <Rollingcardstack />;
}
```
