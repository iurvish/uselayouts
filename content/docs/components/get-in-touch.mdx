## Features

- **Glossy pill**: Dark gradient, inset highlight, and a press scale on the CTA shell.
- **Two-beat hover**: Portrait and YOU fly in, then snap together before the new label appears.
- **Focus too**: Keyboard focus runs the same sequence as hover.
- **Custom copy**: Pass `defaultText`, `hoverText`, and `imageSrc`.
- **Reduced motion**: The sequence cuts to the end state. The link still works.

## Usage

Needs `motion`. Point `href` at a contact route or `mailto:`. Swap `imageSrc` for your portrait.

```tsx
import GetInTouch from "@/components/get-in-touch";

export default function Example() {
  return <GetInTouch />;
}
```

## Where to use

- Portfolio and personal site headers
- Contact and booking CTAs
- About pages
- Agency landing footers
- “Work with me” strips
