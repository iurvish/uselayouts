---
title: Status Fan
description: A card header with a cascading fan of status pills that animate open and crossfade between the title and selected status label.
---

## Usage

```tsx
import { StatusFan } from "@/components/status-fan";

export default function Page() {
  return (
    <div className="flex items-center justify-center min-h-screen">
      <StatusFan title="Polyphonic workbench" />
    </div>
  );
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | — | The card title shown when the picker is closed. |
| `defaultStatusId` | `"changes" \| "progress" \| "archived" \| "approved" \| "review"` | `"progress"` | The initially selected status. |

## Features

- **Cascading Fan** — Status pills fan out vertically with a staggered spring animation, creating a stacked tag look.
- **Crossfade Title** — The header crossfades between the card title and the selected status label when the picker opens.
- **Outside Click Dismissal** — Clicking anywhere outside the header/fan closes the picker.
- **Spring Physics** — Crisp, bouncy spring transitions tuned for tactility (`stiffness: 520, damping: 42, mass: 0.72`).
- **Hover & Tap Feedback** — Pills scale up on hover (`1.045`) and press down on tap (`0.96`).
