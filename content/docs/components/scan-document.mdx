## Features

- **Unfold from the button**: The page grows up from the bottom, then settles.
- **Physical flip**: A full `rotateY` cycle with a spine, front lines, and a gray back.
- **Scan light**: An orange bar travels down, pauses, and returns. Two copies stay visible through the flip.
- **Status copy**: Scan → Scanning → Done. The label is the source of truth, not the motion.
- **Auto-reset**: After Done, it returns to Scan so you can run it again.
- **Reduced motion**: No 3D cycle. A short fade, then Done, then reset.

## Usage

Needs `motion`. Click once. It disables itself while scanning, then resets on its own.

```tsx
import ScanDocument from "@/components/scan-document";

export default function Example() {
  return <ScanDocument />;
}
```

## Customize

- **Duration**: `SCAN_DURATION_MS` (default 5000). Keep `SCAN_EXIT_DURATION_SECONDS` inside that budget.
- **Scan bar**: Orange Tailwind stops and glow shadows on `ScanBar`.
- **Document size**: `110px × 150px` on the perspective wrapper.
- **Button**: Lime bottom border, primary fill. Swap those classes.
- **Reset**: `DONE_RESET_DELAY_MS` is how long Done stays before Scan returns.
- **Icon**: Replace `Icon`. Keep it 16px in the button.
- **3D intensity**: `DOCUMENT_ROTATE_Y` and `[perspective:900px]`. Flatten the array to skip the flip.
