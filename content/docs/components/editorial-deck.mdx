---
title: Editorial Deck
description: A stacked editorial story deck. Drag the front card and it springs back into the pile.
---

## Usage

```tsx
import EditorialDeck from "@/components/editorial-deck";

export default function Example() {
  return <EditorialDeck />;
}
```

## Features

- Drag or swipe the front story to send it to the back
- Spring settle into the stack — no pop or vanish
- Optional title and subtitle (hidden when empty)
