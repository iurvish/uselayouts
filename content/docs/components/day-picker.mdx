## Features

- **Frequency first**: Daily, Weekly, Monthly, Yearly sit in a morphing pill.
- **Day chips**: When weekly is on, Sun–Sat appear so you can tap several days.
- **Blur swap**: Opening the option row blurs the “Frequency” label so focus stays on the choice.
- **Spring resize**: The card grows and shrinks with the content — no leftover empty box.
- **Summary when closed**: Collapse it and you still see what you picked.

## Usage

Meant for schedules, reminders, and billing cadence — not a full calendar. Drop it in a form or settings sheet. You’ll mostly change the `options` array. Give it a compact column (~320px); it already looks like a native control.

```tsx
import FrequencySelector from "@/components/day-picker";

export default function Page() {
  return <FrequencySelector />;
}
```

## Where to use

- Recurring-task or reminder settings
- Billing period pickers
- Calendar-app onboarding
- Newsletter or digest cadence
- Booking flows that need “which days”
