## Features

- **Name on a wheel**: Labels sit on an arc; the selected one rests at the apex.
- **Photo lockup**: A large still on the side crossfades as you move.
- **Drag, wheel, keys**: Pointer, trackpad, and arrows all snap to an item.
- **Momentum then snap**: Flicks coast, then settle on a name.
- **Edge fade**: Labels dissolve at the ends of the arc so the list never looks cut off.

## Usage

Feed it items with a label and an image. Needs a wide stage — this is a catalog, not a chip. Long names may need a slightly larger radius. Same interaction language as a Ferris-wheel picker.

```tsx
import Urvish from "@/components/urvish";

export default function Example() {
  return <Urvish />;
}
```
