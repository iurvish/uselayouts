## Usage

```tsx
import VerticalTabs from "@/components/vertical-tabs";

export default function Example() {
  return <VerticalTabs />;
}
```

## Features

- Vertical index: 01 Web Design, 02 Framer, 03 Branding — click any row.
- Progress on the active: A bar fills while autoplay holds that tab.
- Synced still: The big photo and copy swap with the selection.
- Directional slide: Next vs previous enter from opposite sides.
- Pause on hover: Auto-cycle stops when you’re reading.
