## Features

- **Vertical index**: 01 Web Design, 02 Framer, 03 Branding — click any row.
- **Progress on the active**: A bar fills while autoplay holds that tab.
- **Synced still**: The big photo and copy swap with the selection.
- **Directional slide**: Next vs previous enter from opposite sides.
- **Pause on hover**: Auto-cycle stops when you’re reading.

## Usage

Fill `SERVICES` with title, description, and image. Needs a two-pane layout (list + picture). Autoplay is five seconds in the demo. Three to five items is the right length; more and the list gets long. Good as a services or capabilities block.

```tsx
import VerticalTabs from "@/components/vertical-tabs";

export default function Page() {
  return <VerticalTabs />;
}
```

## Where to use

- Agency services pages
- Product capability tours
- Studio homepages
- Course or curriculum outlines
- Case-study chapter navigation
