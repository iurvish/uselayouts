## Features

- **Folder tab**: Numbered 01, 02, 03 cards sit like file folders, not generic tiles.
- **Hover lift**: The folder comes forward; a 3D object (palette, camera, plant) floats above it.
- **Photo peek**: A background still shows through the folder body so each card has a scene.
- **Tinted paper**: Soft lilac, peach, and mint fills with matching type colors.
- **Optional link**: The whole card can be an `<a>` if you pass `href`.

## Usage

Three cards in a row is the intended look. You’ll change titles, folder colors, Unsplash stills, and the emoji object. Needs hover (or a tap equivalent) and a tall-ish card height. Don’t stack too many — three folders already tell the story.

```tsx
import CardFolder from "@/components/card-folder";

export default function Example() {
  return <CardFolder />;
}
```

## Where to use

- Studio service or offering cards
- Case-study indexes
- Product category tiles
- Mood-board or campaign “shot lists”
- Landing grids that want objects, not icons
