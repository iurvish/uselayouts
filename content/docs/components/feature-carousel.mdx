## Features

- **Chip rail**: Labels like Sustainable Sourcing and Cloud Ready sit as floating pills.
- **Synced still**: The large image card updates to match the selected chip.
- **Scroll into view**: The active chip is brought into the rail so you never lose it.
- **Auto-play, then pause**: It cycles on its own and stops when you hover.
- **Icon + one-liner**: Each feature has a glyph and a short description under the photo.

## Usage

Fill the `FEATURES` array with label, icon, image, and a sentence. Needs a two-column-ish layout (chips + picture). Autoplay is nice on a homepage; pause it on a pricing page where people are comparing. Eight items is plenty — more and the rail gets long.

```tsx
import FeatureCarousel from "@/components/feature-carousel";

export default function Page() {
  return <FeatureCarousel />;
}
```

## Where to use

- Product marketing feature tours
- Brand story pages
- Food, travel, or lifestyle brand sites
- SaaS “platform” sections
- Conference or festival highlights
