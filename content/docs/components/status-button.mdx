## Features

- **Three states**: Idle, loading, success in one control.
- **Letter morph**: Characters blur and scale as the word changes — not a spinner-only trick.
- **Corner pip**: A small indicator appears while it’s working or done.
- **Disabled mid-flight**: You can’t double-submit while it’s saving.
- **Back to idle**: After success it returns so you can save again.

## Usage

Call it on a real save. Replace the timeouts with your request: idle → loading on click, success when the server answers. Keep the label short (Save / Saving / Saved). Sit it in a form footer or an editor chrome.

```tsx
import { SaveButton } from "@/components/status-button";

export default function Page() {
  return <SaveButton />;
}
```

## Where to use

- Settings save bars
- Document or canvas editors
- Profile forms
- Admin consoles
- Checkout “place order” if you keep the three words honest
