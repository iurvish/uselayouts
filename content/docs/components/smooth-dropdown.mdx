---
title: Smooth Dropdown
description: A round trigger that morphs into a menu — items stagger in, the shell resizes, click outside to close.
---

## Features

- **Shape morph**: The button becomes the menu without a pop-in overlay.
- **Staggered rows**: Profile, Upgrade, and the rest arrive in sequence.
- **Active and hover**: The current row is obvious; hover doesn’t fight it.
- **Outside click**: The menu collapses when you click away.
- **Spring, not fade**: Height and items share one physical motion.

## Usage

Use it as an account or overflow menu. Edit `menuItems` for labels and icons. Needs a click and a little space below the trigger. Don’t nest it in a overflow:hidden parent or the morph will clip. Wire rows to real routes.

```tsx
import MenuInteraction from "@/components/smooth-dropdown";

export default function Page() {
  return (
    <div className="flex items-center justify-center h-[400px] w-full">
      <MenuInteraction />
    </div>
  );
}
```

## Where to use

- Account menus in a header
- Upgrade / billing overflow
- Compact app toolbars
- Mobile more-menus
- Prototype nav without a full dropdown library
