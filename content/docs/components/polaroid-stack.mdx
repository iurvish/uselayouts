## Features

- **Idle pile**: Same size, white frame, thick Polaroid foot, stacked on center.
- **CSS fan**: Parent `group-hover` rotates cards from −54° to 54°. No Motion, no JS state.
- **Shared hinge**: `origin-bottom-left` so they pivot from one hand-held point.
- **Card lift**: A single print scales to 1.1 on its own hover and rises above the rest.
- **Fine pointer only**: The fan stays off on touch. Reduced motion keeps the pile still.

## Usage

Hover the section. Swap `fanCards` for your shots. This is a stack, not a carousel.

```tsx
import PolaroidStack from "@/components/polaroid-stack";

export default function Example() {
  return <PolaroidStack />;
}
```

## Customize

- **Count**: Add or remove items in `fanCards`. Spread `hoverClassName` rotations evenly.
- **Size**: `h-[226px] w-[152px]` on `cardClassName`.
- **Fan angle**: The `rotate(...)` values. Keep the middle card at `0deg`.
- **Speed**: `duration-200`. Keep it at or under 300ms.
- **Photos**: `src` and `alt` on each card.
- **Border**: `border-[5px]` and `border-b-[40px]` for the Polaroid foot.
- **Scale**: `hover:[scale:1.1]`.
