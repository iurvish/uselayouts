---
title: LogoShift
description: A grid of brand marks that take turns sliding, fading, or flipping into the next logo.
---

## Features

- **Column shuffle**: Each cell cycles its own stack of logos on a timer.
- **Staggered ripple**: Columns don’t all change at once — a small delay walks across the grid.
- **Three motions**: Vertical slide, fade, or flip — pick one language.
- **Pause on hover**: Rest the grid while someone is reading a mark.
- **Layout variants**: Grid, cards, glass, or minimal cells.

## Usage

Drop it as a “used by” or partner wall. Pass columns of SVG marks or image URLs. Interval and stagger are props. Keep the grid wide enough that logos stay legible; don’t put tiny wordmarks in a four-column crush.

```tsx
import Logoshift from "@/components/logoshift";

export default function Example() {
  return <Logoshift />;
}
```

## Where to use

- Homepage logo walls
- Pricing “trusted by” rows
- Partner or integration pages
- Conference sponsor grids
- Case-study client lists
