---
title: Tactile Button
description: A liquid-glass rocker that tilts into its well when you press it.
---

## Usage

```tsx
import TactileButton from "@/components/tactile-button";

export default function Example() {
  return <TactileButton />;
}
```

## Features

- Rocker press: The cap tilts and sinks into a recessed well with a spring.
- Glass sheen: Specular highlight and inset shadows so it reads as a physical switch.
- LED bead: A glass indicator lights on hover and press (blue, green, amber, red, or slate).
- Sizes: `sm`, `default`, and `lg`. `fullWidth` stretches it.
