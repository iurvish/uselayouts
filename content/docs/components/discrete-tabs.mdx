title: Discrete Tabs
description: Quiet icon tabs that expand to a label, with a brief shine when one becomes active.
---

## Features

- **Icon, then name**: Inactive tabs stay compact; the active one grows to show Inbox, Planner, or Alerts.
- **Shared layout**: The pill slides with a spring so neighboring tabs don’t jump.
- **Shine on select**: A short highlight flashes across the active tab, then it’s gone.
- **Custom glyphs**: Inbox, calendar, and bell are inline SVGs — easy to swap.
- **No underline circus**: Motion is the indicator; you don’t need a second chrome bar.

## Usage

Use it as a small mode switch, not a page of content. Three tabs is the sweet spot. Put the panels yourself underneath — this only handles the control. Fine in a toolbar, a settings header, or a mail-style app chrome.

```tsx
import DiscreteTabs from "@/components/discrete-tabs";

export default function Page() {
  return <DiscreteTabs />;
}
```

## Where to use

- Mail or inbox toolbars
- Planner vs alerts vs inbox in a productivity app
- Compact settings headers
- Mobile app top chrome
- Dashboard section switches
