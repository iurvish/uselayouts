---
title: Fluid Expanding Grid
description: A photo grid where clicking one image makes it take the row while neighbors slide aside.
---

## Features

- **One expands, others yield**: Highlands, Crimson, Deep Sea — click one and it owns the row.
- **Row reshuffle**: Neighbors drop to the next row instead of overlapping.
- **Color wash**: Each cell carries an accent that eases in with the photo.
- **Title overlay**: Name and subtitle sit on the still once it’s open.
- **Layout animation**: Cells morph with motion layout, not a hard reflow.

## Usage

Works with a small set of images (three or four). Click to expand; clicking the already-solo item does nothing — that’s on purpose. Give it a full-width gallery well. Swap `ITEMS` for your own titles, subtitles, and photos.

```tsx
import FluidExpandingGrid from "@/components/fluid-expanding-grid";

export default function Page() {
  return <FluidExpandingGrid />;
}
```

## Where to use
