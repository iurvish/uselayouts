## Features

- **Arc of labels**: Titles ride a wheel; the selected one sits at the apex.
- **Synced still**: The large photo updates as the wheel turns.
- **Drag and snap**: Pointer and scroll coast, then lock to an item.
- **Keyboard too**: Arrows step through the list without the mouse.
- **Edge fade**: Names dissolve at the top and bottom of the arc.

## Usage

Pass a list of labels and images. Give it a wide preview — photo plus wheel. Tune spacing if your titles are long. Treat it as a catalog browser on a marketing page, not a form control.

```tsx
import NewComponent from "@/components/new-component";

export default function Example() {
  return <NewComponent />;
}
```

## Where to use

- Project or property catalogs
- Lookbooks and campaign archives
- Exhibition or museum indexes
- Studio selected-work pages
- Travel or hospitality galleries
