## Features

- **Arc of labels**: Titles sit on a wheel; the selected one sits at the apex.
- **Photo lockup**: A large still on the side crossfades as the wheel moves.
- **Drag, wheel, keys**: Pointer, trackpad, and arrows all snap to an item.
- **Momentum then snap**: Flicks coast, then settle on a name.
- **Edge fade**: Labels dissolve at the top and bottom of the arc so the list never looks clipped.

## Usage

Pass items with `label` and `image` (architecture, interiors, landscapes in the demo). Needs a wide stage — photo + wheel. This is a catalog browser, not a tiny widget. Tune radius and visible count if your names are long.

```tsx
import WheelCarousel from "@/components/wheel-carousel";

export default function Example() {
  return <WheelCarousel />;
}
```
