title: Memory Card Stack

---

## Usage

```tsx
import MemoryCardStack from "@/components/memory-card-stack";

export default function Page() {
  return <MemoryCardStack />;
}
```

## Features

- **Hover fan-out** — three photo cards spread apart on hover or focus
- **Parallax tilt** — cards respond to mouse movement with a soft 3D tilt
- **Spring physics** — spring-based fan-out with staggered float animations
- **Reduced motion** — respects the `prefers-reduced-motion` preference
- **Keyboard accessible** — focusable with `aria-expanded` for assistive tech
