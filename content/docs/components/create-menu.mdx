## Features

- **Island morph**: The pill grows from a single button into a stacked menu with a spring.
- **Create actions**: Post, idea, thread, template, repurpose, and AI tool in one place.
- **Click outside**: The menu folds back to the button when you click away.
- **Sidebar-shaped demo**: Shown in a fake app chrome so you see where it lives.

## Usage

Keep it near the top of a sidebar or editor chrome. Edit the items array for your create types. Give the parent `overflow-visible` so the expanding menu isn’t clipped.

```tsx
import CreateMenu from "@/components/create-menu";

export default function Page() {
  return <CreateMenu />;
}
```

## Where to use

- Writing or CMS sidebars
- Social scheduling tools
- AI content studios
- Project “new” menus
- Dashboard empty states that start with create
