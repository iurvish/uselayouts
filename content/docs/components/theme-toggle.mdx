title: Theme Toggle
description: A physical switch with a dotted grip. Click and the knob slides across a recessed track, then the chrome flips with it.
---

## Features

- **Dotted grip**: Twelve dimples on a raised square knob, like a hardware switch.
- **Inset track**: The well is carved into the pill so the knob sits in real depth.
- **Slide then color**: The knob moves first. The track fills after.
- **Light and dark chrome**: Off is pale gray. On is slate with a teal well.
- **Reduced motion**: The slide shortens. The state still changes.

## Usage

Drop it on a quiet stage. Click or tap. Wire the checkbox if you need the value.

```tsx
import ThemeToggle from "@/components/theme-toggle";

export default function Example() {
  return <ThemeToggle />;
}
```

## Where to use

- Settings and preference rows
- Theme pickers
- Hardware-feeling dashboards
- On/off controls on a pale ground
- Motion portfolio pieces
