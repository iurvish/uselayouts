title: Theme Toggle
description: A physical switch with a dotted grip. Click and the knob slides across a recessed track.
---

## Usage

```tsx
import ThemeToggle from "@/components/theme-toggle";

export default function Example() {
  return <ThemeToggle />;
}
```

## Features

- Dotted grip: Twelve dimples on a raised square knob, like a hardware switch.
- Inset track: The well is carved into the pill so the knob sits in real depth.
- Slide then color: The knob moves first. The track fills after.
- Light and dark chrome: Off is pale gray. On is slate with a blue well.
- Reduced motion: The slide shortens. The state still changes.
