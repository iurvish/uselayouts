---

## Features

- **Gooey bridges**: SVG necks grow between the active and hovered pills.
- **Neighbor push**: Tabs slide apart so the melt has room.
- **Cursor halo**: A radial glow follows the pointer across the contour.
- **Active dot**: A 4px mark sits under the current page.

## Usage

Pass `items` with `label` and `link`. Control it with `activeIndex` / `onSelect`, or leave it uncontrolled.

```tsx
import GooeyNavbar from "@/components/gooey-navbar";

export default function Page() {
  return <GooeyNavbar />;
}
```

## Where to use

- Marketing site headers
- Studio or agency nav
- Portfolio section jump
- Product landing pages
- Any short, five-or-fewer item nav
