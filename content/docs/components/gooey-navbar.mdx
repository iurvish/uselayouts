---
title: Gooey Navbar
description: A pill nav that melts into its neighbor when you hover — liquid bridges, active dot.
---

## Usage

```tsx
import GooeyNavbar from "@/components/gooey-navbar";

export default function Example() {
  return <GooeyNavbar />;
}
```

## Features

- Gooey bridges: SVG necks grow between the active and hovered pills.
- Neighbor push: Tabs slide apart so the melt has room.
- Active dot: A 4px mark sits under the current page.
