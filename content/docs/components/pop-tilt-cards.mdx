## Features

- **Overlap fan**: Cards sit offset like a hand of color chips — Bloom, Mist, Meadow, Coral.
- **Pop on hover**: The active card lifts about a hundred pixels and scales a hair.
- **Neighbors tilt**: Cards to the left lean one way, cards to the right the other, so a gap opens.
- **No photos**: Soft fills and a word — the motion is the whole show.
- **Settle spring**: Hover doesn’t wobble; it stops cleanly.

## Usage

This is a hover piece. Put it on a wide desktop section; touch won’t get the same split. Swap titles and pastel fills. Eight cards is the demo — fewer still works, more gets crowded. Don’t put links on every card unless you want a busy hit area.

```tsx
import PopTiltCards from "@/components/pop-tilt-cards";

export default function Example() {
  return <PopTiltCards />;
}
```

## Where to use
