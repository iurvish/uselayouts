title: Flower Menu
description: A plus button that blooms ten icon discs outward onto a ring, on a stagger, and turns into a cross.
---

## Usage

```tsx
import FlowerMenu from "@/components/flower-menu";

export default function Page() {
  return <FlowerMenu />;
}
```

The component brings its own 420px panel and background, so it needs no wrapper.

## Features

- **Radial bloom** — ten discs travel out to an 88px ring, spaced evenly and starting from twelve o'clock.
- **Staggered out, reversed back** — each disc leaves 35ms after the one before it; closing runs last-disc-first.
- **A spring that overshoots** — opening uses `stiffness: 300, damping: 15, mass: 0.6`, under critical damping, so the discs pass the ring and settle. Closing is a 0.5s `[0.22, 1, 0.36, 1]` curve.
- **Plus into cross** — the centre icon rotates 135° over the same curve.
- **Resolving from blur** — discs scale up from 0.5 and clear a 4px blur as they travel.
- **Inert while closed** — the satellites drop their pointer events, so only the trigger is clickable.
- **Dark mode** — the disc shadow is a CSS variable with a separate dark set, scoped so a `.light` island inside a dark page still wins.

## Customization

Icons come from a flat `ITEMS` array — each entry is an `id` and a `lucide-react` icon. Positions are computed, not declared, so adding an entry re-spaces the whole ring:

```tsx
const ITEMS: FlowerItem[] = [
  { id: "bell", icon: Bell },
  { id: "sparkles", icon: Sparkles },
  // ...
];
```

`RADIUS` sets how far the discs travel, and `STEP` divides the circle by however many items there are:

```tsx
const RADIUS = 88;
const STEP = (Math.PI * 2) / ITEMS.length;
```

For a different feel, tune the opening spring inline on the satellites, and `EASE` for the close and the plus rotation:

```tsx
const EASE = [0.22, 1, 0.36, 1] as const;
```
